

## AI-BLOGGER

AI-BLOGGER is a modern, AI-powered blogging platform built with Next.js, TypeScript, ConvexDB, Gemini AI, and Clerk Auth.


# 🚀 Features

✨ AI-Powered Blogging – Generate blog posts, summaries, and content ideas using Gemini AI.

🔐 Secure Authentication – User sign-up, login, and session management powered by Clerk Auth.

📦 Serverless Database – Store posts, drafts, and user data with ConvexDB.

⚡ Next.js + TypeScript – Fully typed, modern React framework with server-side rendering & static generation.

🎨 Responsive UI – Clean, user-friendly design optimized for all devices.
